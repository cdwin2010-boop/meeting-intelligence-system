# v3.0 UI 유사 업무 검색·대체·대체 요청 (작업 71-1 파트 B)

백엔드(66-4)가 완성돼 있고, 이 화면은 서버가 준 허용 동작(`allowedActions`)으로만 버튼을 보인다(직급·역할로 추정하지 않음). 정책: 오늘 회의가 최우선, 자동 병합 없음, 담당자는 "대체 요청", 프로젝트 총괄·부서장·지시자는 "직권 대체". 직권 종료·직권 취소는 새 기능이 아니라 기존 업무 종결(구분 "직권 종료")과 삭제(사유 필수)를 쓴다.

## 사용 API
| 호출 | 쓰임 |
|---|---|
| `GET /api/action-items/{id}/similar` | 유사 업무 후보: itemId·title·assignee·dueDate·status·score(0~100)·reasons·meeting{id,title,heldAt} |
| `POST /api/action-items/{newItemId}/supersede` `{supersedesItemId, reason}` | 직권 대체. 403·409·422 는 서버 문구를 팝업 안 알림으로 보인다 |
| `POST /api/meetings/{id}/change-requests` `{comment, itemId, kind:"supersede", supersedesItemId}` | 대체 요청(수정 요청의 한 종류) |
| 회의록 상세 업무 `supersededBy`·`supersedes` | 대체 정보(상대 회의록을 열람할 수 없으면 meetingTitle null) |
| 수정 요청 응답·수정 요청 대기 응답 `kind`·`supersedesItemId` | 대체 요청 표시 |

## 화면 구성
- **업무 원장**: 상태 칸 — 대체된 업무는 "대체됨" 칩(대체됨 토큰·취소선, 색 외 글자 라벨). 업무명 칸 — "대체한 업무: {회의록 제목}" 링크(제목 null 이면 링크 없이 "열람 권한이 없는 회의록"), 대체하는 업무는 "대체한 과거 업무 N건"과 항목별 링크("대체한 과거 업무 보기: {회의록 제목}"). 동작 칸 — `find_similar_items` 가 있으면 [유사 업무 검색](접근성 이름 "유사 업무 검색: {업무명}"). 열 폭 규칙은 그대로이고 새 버튼은 기존 동작 칸 줄바꿈 안에 들어간다.
- **유사 업무 검색 팝업**: 열면 GET similar 호출(로딩 → 결과, 오류+"다시 시도", 빈 결과 "비슷한 과거 업무가 없습니다"). 결과 목록 이름 "유사 업무 후보", 점수 높은 순 카드: 업무명·상태 라벨·담당자·기한·회의록 제목(링크, 같은 탭)·일시, "유사도 N점"과 막대, 이유 칩. 카드 동작은 기준 업무의 allowedActions 로 정한다: `request_supersede` → [대체 요청], `supersede_item` → [직권 대체]. 카드마다 "회의록에서 직접 처리하려면 회의록 열기" 링크(과거 회의록에서 기존 종결·삭제를 쓴다).
- **사유 팝업**(ReasonDialog 재사용, 사유 필수·2000자): 대체 요청은 확인 버튼 "대체 요청 올리기", 직권 대체는 "직권 대체". 성공하면 검색 팝업을 닫고 원장·수정 요청 목록을 다시 받아 결과를 알린다("{업무명}: 대체 요청을 올렸습니다" / "직권 대체했습니다"). 서버 거부는 팝업 안 `role="alert"`, 입력 유지, 제출 중 중복 클릭 방지. 닫으면 [유사 업무 검색] 버튼으로 포커스가 돌아간다.
- **수정 요청 표시**: kind="supersede" 요청은 "대체 요청" 배지와 "대체될 업무 #{id}"를 보인다(수정 팝업 내역, 할 일 화면의 수정 요청 대기). kind="edit" 요청의 표시는 그대로다. 수락은 기존 "답변·해결" UI 그대로이며, 대체 요청 수락이 403·409 로 거부되면 서버 문구를 알림으로 보이고 요청은 해결 대기로 남는다.

## 동작별 노출
| 서버 allowedActions | 업무 원장 | 검색 팝업 카드 |
|---|---|---|
| (대체 동작 없음) | 버튼 없음 | — |
| `find_similar_items` + `request_supersede` | [유사 업무 검색] | [대체 요청] |
| 위 + `supersede_item` | 같음 | [대체 요청] [직권 대체] |
| 대체된 업무 | `request_change` 외 쓰기 동작 없음, "대체됨" 칩 | — |

## 아직 하지 않은 것
오른쪽 패널의 승인 큐, 검색 팝업 안의 직권 종료·직권 취소(과거 회의록에서 기존 종결·삭제를 쓴다), 대체 취소·정정.
